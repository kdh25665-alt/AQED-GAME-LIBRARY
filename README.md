# AQED Game Library

مكتبة ويب عربية متجاوبة تعمل على الكمبيوتر والجوال ومتصفح PS4. المشروع حالياً واجهة مكتبة وإدارة بيانات وروابط تحميل HTTPS؛ لا يقوم بتثبيت PKG تلقائياً على الجهاز.

## المتطلبات
- Node.js 18 أو أحدث
- لا توجد حزم خارجية مطلوبة

## التشغيل
```bash
npm start
```
ثم افتح `http://localhost:3000`.

## إعداد رمز الإدارة
غيّر الرمز الافتراضي قبل النشر:

Linux/macOS:
```bash
ADMIN_TOKEN='ضع-رمزاً-طويلاً-هنا' PORT=3000 npm start
```

Windows PowerShell:
```powershell
$env:ADMIN_TOKEN='ضع-رمزاً-طويلاً-هنا'
$env:PORT='3000'
npm start
```

افتح «لوحة الإدارة»، أدخل الرمز، ثم أضف اسم اللعبة والتصنيف والإصدار والحجم وصورة الغلاف ورابط HTTPS. البيانات تحفظ في `data/games.json`.

## النشر والاستخدام على PS4
انشر المشروع على استضافة تدعم Node.js مع HTTPS، ثم افتح رابط الموقع من متصفح PS4. الواجهة تدعم النقر والتنقل بعناصر HTML القياسية. زر التحميل يفتح رابط الملف الذي أضفته؛ تنزيل/تثبيت ملفات PKG يعتمد على إعدادات الجهاز وأدوات التثبيت الموجودة عليه ولا ينفذه الموقع بنفسه.

## ملاحظات تشغيلية
- استخدم روابط ملفات تملك حق توزيعها فقط.
- غيّر `ADMIN_TOKEN` من القيمة الافتراضية، ولا تترك لوحة الإدارة مكشوفة برمز معروف.
- يفضّل وضع الموقع خلف HTTPS ونسخ `data/games.json` احتياطياً.
- صور الأغلفة التجريبية روابط placeholder ويمكن استبدالها بروابط صورك.
- قاعدة البيانات JSON مناسبة كبداية صغيرة؛ عند تعدد المديرين أو كثافة الاستخدام انقلها إلى SQLite وأضف جلسات دخول وحدود طلبات.
